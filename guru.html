Petunjuk Penggunaan Panel Guru

Selamat datang di Sistem Ujian Online. Langkah umum persiapan ujian:

  1. Buka menu Kelas untuk membuat rombel (contoh: VII A).
  2. Buka menu Siswa untuk memasukkan daftar murid.
  3. Buka menu Ujian untuk membuat jadwal dan token ujian.
  4. Input soal manual di Tambah Soal atau import massal via Import Excel.
  5. Gunakan format $...$ untuk memasukkan notasi matematika (contoh: $2\frac{1}{3}$).
  6. Bagikan Token Ujian kepada siswa untuk mulai mengerjakan.
